## Contrato

Es la interfaz que el test invoca y no admite variantes.

1. Invocación: `python3 vida.py <archivo_estado_inicial> <generaciones>`. Dos argumentos
   posicionales, en ese orden. `<generaciones>` es un entero mayor o igual a cero.
2. El archivo de estado es una grilla rectangular: una línea por fila, `#` célula viva, `.`
   célula muerta.
3. Regla de transición (B3/S23), con vecindad de Moore, las 8 celdas adyacentes:
   una célula viva con 2 o 3 vecinas vivas sobrevive y con cualquier otra cantidad muere;
   una célula muerta con exactamente 3 vecinas vivas nace.
4. El mundo es finito, del tamaño de la grilla: toda posición fuera de los bordes está muerta,
   nunca se ocupa y no se cuenta como vecina viva. **Sin wrap-around**: el borde no se conecta
   con el borde opuesto.
5. La actualización es simultánea: la generación N+1 se calcula íntegramente a partir de la N.
6. El script imprime por stdout la grilla resultante tras N generaciones, en el mismo formato y
   con las mismas dimensiones que la de entrada: una línea por fila, nada más. Sin encabezados,
   sin número de generación, sin líneas en blanco de más, sin mensajes de progreso.
7. Con `<generaciones>` igual a 0 imprime el estado inicial tal cual.

## Restricciones

import sys

def main():
    if len(sys.argv) != 3:
        sys.exit("Uso: python3 vida.py <archivo_estado_inicial> <generaciones>")

    archivo = sys.argv[1]
    generaciones = int(sys.argv[2])

    with open(archivo, 'r') as f:
        lineas = f.read().splitlines()

    # Ignorar líneas vacías al final
    while lineas and lineas[-1] == '':
        lineas.pop()

    if not lineas:
        return

    grid = [list(linea) for linea in lineas]
    filas = len(grid)
    columnas = len(grid[0])

    for _ in range(generaciones):
        nuevo = [['.' for _ in range(columnas)] for _ in range(filas)]

        for i in range(filas):
            for j in range(columnas):
                vecinas = 0
                for di in (-1, 0, 1):
                    for dj in (-1, 0, 1):
                        if di == 0 and dj == 0:
                            continue
                        ni = i + di
                        nj = j + dj
                        if 0 <= ni < filas and 0 <= nj < columnas:
                            if grid[ni][nj] == '#':
                                vecinas += 1

                if grid[i][j] == '#':
                    if vecinas == 2 or vecinas == 3:
                        nuevo[i][j] = '#'
                    else:
                        nuevo[i][j] = '.'
                else:
                    if vecinas == 3:
                        nuevo[i][j] = '#'
                    else:
                        nuevo[i][j] = '.'

        grid = nuevo

    salida = '\n'.join(''.join(fila) for fila in grid)
    sys.stdout.write(salida + '\n')

if __name__ == '__main__':
    main()
